# TS\-Native 跨Web框架原生渲染解决方案（脱离浏览器、全框架兼容架构）

## 一、方案核心定位

### 1\.1 设计初衷

现有TS\-Native渲染体系基于Vue Runtime\-Core搭建，实现了脱离DOM的原生画布渲染，但存在**框架绑定局限**，仅支持Vue模板/TSX开发，无法适配React、原生TSX等主流前端开发范式，限制了生态包容性与开发者迁移自由度。

基于TS\-Native已落地的**原生DOM子集、标准TSX解析、Yoga布局、Skia绘制、AOT静态编译**核心能力，本方案彻底打破单一Web框架绑定，构建**通用、无框架依赖、兼容全前端生态**的原生桌面渲染架构。实现开发者无需适配框架、可自由选用「Vue/React/原生TSX/原生DOM」任意范式开发桌面原生应用，全程脱离浏览器、WebView、Node运行时，最终编译为独立二进制文件。

### 1\.2 核心设计理念

1. **去框架中心化**：不绑定Vue、React等任何Web框架，构建通用组件渲染、响应式、TSX解析底层基座，所有Web框架语法统一适配、统一渲染。

2. **语法完全兼容**：1:1对齐主流前端开发规范，Vue SFC、React JSX/TSX、原生DOM API、原生TSX全部开箱即用，零开发者语法改造。

3. **底层统一收敛**：所有上层框架语法、组件逻辑，最终收敛至同一套「TS\-Native DOM子集\+Yoga布局\+Skia绘制」原生渲染链路，性能一致、表现统一。

4. **轻量化按需适配**：摒弃Web框架冗余内核，仅适配框架上层语法特性，保留开发习惯，剥离浏览器历史包袱，最大化原生性能优势。

5. **AOT全链路静态编译**：所有框架代码统一参与全局AOT编译，无运行时框架解析、无动态适配开销，产物为单文件原生二进制。

### 1\.3 能力边界与核心优势

**突破原有方案局限**：从「Vue专属原生渲染」升级为「全前端生态通用原生渲染」，覆盖99%前端开发范式，解决多框架项目迁移、多技术栈团队适配、原生桌面应用灵活开发的核心痛点。

**差异化核心优势**：区别于Electron、Tauri等依赖Web内核的方案，本架构无需浏览器环境，同时兼容所有Web框架开发习惯，兼具**原生二进制高性能、前端低学习成本、多框架自由选型**三重特性。
